# OpenAPI 兼容性记录

## 0.2.0 — 2026-10-13

完成第 5–7 步：完整规范新增 25 个客户端、33 个后台、3 个认证操作，共 66 个；提供双语请求、响应、权限、修订、生命周期、multipart 图片和 WebP 二进制响应。Scalar 默认完整规范，可切换公开规范；公开入口保持原五个 GET。

不修改业务处理、数据库权限、签名、发布或分发行为。澄清新平台无关 v2 公开响应不含 platform；历史平台限制及管理下载 universal 标识保留。旧 metadata draft 接口保留，标记 deprecated 并说明不能替代完整上传。

新增实际请求校验提取、独立路由覆盖、实现摘要、AJV 真实 HTTP 契约测试、兼容性检测、CI 和公开 artifact 发布。公开基线为 `baselines/public-0.1.0.json`，完整规范首次基线为 `baselines/admin-0.2.0.json`。

Scalar 调试适配修复：当渲染器传入 Request 对象时保留其 JSON／Bearer 请求头，仅移除浏览器禁止手填的 Origin；正常 JSON Cookie 写请求已通过真实浏览器退出验证。

## 0.1.0 — 2026-10-13

第 1–4 步：公开 Launcher 五个操作的 OpenAPI 3.1、66 操作清单、受保护文档入口及内嵌 Scalar、语言／主题、下载和初步规范／下载／浏览器回归。

## 后续审查

接口变化记录触发条件、请求／响应／权限变化、旧调用者影响和迁移方式。已有参数、响应、安全要求或路径变化都触发失败，即使认为兼容也须审查；新增操作及仅说明变化可通过旧基线。

审查后提升文档版本，生成四份规范，将英文规范保存为新版本基线，更新 `scripts/openapi.ts` 的 baseline 引用；保留此前基线和签名历史。生成命令不重写基线，禁止未经审查覆盖基线来消除失败。Scalar Registry、Pages 和自动部署不属于本次完成范围。
