# OpenAPI 兼容性记录

## 0.3.2 — 2026-10-13

用户明确扩大服务器颜色、展示模式与时间的修改权限至范围内 SERVER_EDIT；组织管理员、服务器管理员、服务器编辑均可修改。应用与数据库展示触发器同步放行，读者、跨组织／跨服务器仍拒绝。排序、上架、归档和登记仍限超管。请求字段、响应与路径不变，既有超管调用兼容；记录权限语义扩展，沿用 admin-0.3.1 字段基线及公开基线。新迁移 202610130001_server_display_editor_permissions 不改写既有数据或签名。


## 0.3.1 — 2026-10-13

登记服务器 POST 增加可选 displayMode、displayStartsAt、displayEndsAt，省略保持永久展示。区间要求合法时间及开始早于结束；永久要求时间为空。新增可选请求字段，旧调用兼容，路径、响应和权限不变。兼容性检查对所有已有操作的字段变化要求人工审查，本轮确认仅增加可选登记字段后保存 admin-0.3.1 新基线，保留 admin-0.2.0；公开基线不变。服务器详情向 SERVER_EDIT 角色明确展示颜色与模式，修改仍限超管。


## 0.3.0 — 2026-10-13

新增上传、草稿和发布的三个 `distribution-statistics` GET，完整规范从 66 增至 69 个操作，公开规范仍为五个 Launcher GET。分别检查 DRAFT_READ／RELEASE_READ 与客户端范围，支持 Cookie／Bearer。返回目标文件声明、固定玩家基准、差异、本地载荷、去重远程下载量、READY 实际 ZIP 大小和已知网络量；环境大小始终 null，未组包时 ZIP／网络量为 null。

这是新增只读能力，不修改既有响应、数据库、历史对象、签名或组包规则。原字段基线继续适用；新增接口契约同步测试与生成产物，详见 [统计口径](v2-distribution-statistics.md)。

## 0.2.1 — 2026-10-13

用户要求服务器箴言改用 2.35:1 电影画幅。图片上传／重新裁剪现在要求 2.35:1 选区，取代 61:23；旧自动化调用者须调整 crop，旧比例写入返回 400。字段、路径、权限和修订检查不变，旧图片／原图／metadata 仍能原样读取，不批量改写；编辑器重新裁剪时以原选区中心适配新比例，保存后创建新对象版本。此比例业务校验属于 JSON Schema 无法自动检查的 refine 语义变化，已人工记录兼容性影响，保留 0.2.0 线级字段基线。

列表图片贴齐整个图片单元格，以表格自身为外框；透明遮罩从横向 61.8034% 渐隐到表格背景，跟随黑白主题和行悬停。编辑／查看预览显示完整图片，无淡出。

## 0.2.0 — 2026-10-13

完成第 5–7 步：完整规范新增 25 个客户端、33 个后台、3 个认证操作，共 66 个；提供双语请求、响应、权限、修订、生命周期、multipart 图片和 WebP 二进制响应。Scalar 默认完整规范，可切换公开规范；公开入口保持原五个 GET。

不修改业务处理、数据库权限、签名、发布或分发行为。澄清新平台无关 v2 公开响应不含 platform；历史平台限制及管理下载 universal 标识保留。旧 metadata draft 接口保留，标记 deprecated 并说明不能替代完整上传。

新增实际请求校验提取、独立路由覆盖、实现摘要、AJV 真实 HTTP 契约测试、兼容性检测、CI 和公开 artifact 发布。公开基线为 `baselines/public-0.1.0.json`，完整规范首次基线为 `baselines/admin-0.2.0.json`。

Scalar 调试适配修复：当渲染器传入 Request 对象时保留其 JSON／Bearer 请求头，仅移除浏览器禁止手填的 Origin；正常 JSON Cookie 写请求已通过真实浏览器退出验证。

## 后续审查

接口变化记录触发条件、请求／响应／权限变化、旧调用者影响和迁移方式。已有参数、响应、安全要求或路径变化都触发失败，即使认为兼容也须审查；新增操作及仅说明变化可通过旧基线。
