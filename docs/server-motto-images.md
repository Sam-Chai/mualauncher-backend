# 服务器箴言图片

2026-10-13：服务器箴言采用固定 **2.35:1** 电影画幅裁剪，不要求固定上传分辨率。此要求替代原 61:23 比例。

## 编辑和展示

点击“上传图片”先打开编辑窗口，再选择 PNG／JPEG／WebP 静态图片。默认选择图片内最大且居中的 2.35:1 区域；三分网格可拖动、使用方向键微调，滑杆缩放选区，支持重置。替换图片重新初始化选区；“重新裁剪”读取保留原图和既有选区，不从已经裁出的图片继续损失范围。

已有服务器“上传并保存”立即保存图片；基础资料表单独立保存，不再提交对象键。新建服务器可以先选好图片，图片随登记表单保存；若服务器登记成功但图片保存失败，保留已登记记录与选区，重试不重复登记。关闭窗口未保存的新图片不上传。

服务器管理表格最左侧为“服务器箴言”列。图片贴齐单元格四边，去除独立圆角和留白，由表格提供外框；从横向 61.8034% 开始透明渐隐，露出当前主题及悬停状态的表格背景。编辑页不使用渐隐，完整显示当前图片；裁剪窗口展示完整原图和选区。存储图片保留完整裁剪内容。无图片显示明确占位。只读／归档资源仅预览；SERVER_EDIT 可上传、重裁剪和移除，服务端再次检查组织／单服范围及活动状态。

## 存储与 API

保留既有 `Server.iconObjectKey` 字段，指向私有 packages bucket 的 `server-mottos/{organizationId}/{serverId}/{imageId}/image.webp`。同一版本目录保存去除 EXIF 等元数据且纠正方向的无损 `source.webp` 和 `metadata.json`（原图大小、归一化裁剪选区、原图及裁图 SHA-256）。不新增数据库迁移，不改客户端包、已发布 Manifest 或签名。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/admin/servers/{serverId}/motto-image` | SERVER_READ，当前裁图 WebP；归档资源仍可读 |
| GET | 同上，`variant=source` | SERVER_READ，保留原图 WebP |
| GET | 同上，`variant=metadata` | SERVER_READ，原图尺寸及裁剪／摘要元数据 |
| POST | 同上 | SERVER_EDIT，multipart 字段 `source`（新文件，可省略以重裁剪当前原图）、`crop`（JSON）、`expectedIconObjectKey`（JSON 字符串或 null） |
| DELETE | 同上 | SERVER_EDIT，JSON `{ expectedIconObjectKey }`，解除图片引用 |

`crop` 是 `{left, top, width, height}`，各值按原图宽／高归一化。服务端校验边界及 2.35:1 比例，以 Sharp 解码后重新生成 WebP，拒绝 SVG、动画、损坏文件、越界或比例不符的选区。新上传文件最多 8 MiB，最多 1600 万像素。显示图输出为 1410×600，不作为用户上传分辨率建议。旧图字节与元数据保持不变；打开旧图重裁剪时，按原选区中心调整为新比例，保存才生成新版本。旧比例的新写入会返回 400，自动化调用须同步调整选区，见 [兼容性记录](openapi-changelog.md)。

所有 API 仅正常后台 Cookie 会话，写请求校验同源；读取私有对象先检查服务器权限，返回 private／no-store／nosniff。可选 `version` 查询值绑定当前图片版本，原图和元数据读取之间发生替换时返回 409。不返回长期 MinIO 凭据或任意对象读取入口。泛用服务器创建／PATCH API 不允许手动指定新的受管理图片引用，旧对象键保持兼容但不假装为可读图片。

解码和存储写入在业务写锁之外完成；最终绑定在事务内重新检查会话、范围、资源状态和 `expectedIconObjectKey`，修改冲突返回 409并记录图片替换／移除审计。每次保存使用新图片版本目录，替换、移除或归档不直接删除旧图。旧图与写入后未绑定的孤立版本目前保留；自动回收尚未接入，不混入客户端 CAS／包回收流程。

## 验证

`npm run test:server-motto` 使用随机 PostgreSQL schema／MinIO 私有桶及隔离 Next 开发实例，检查真实 multipart 上传、图片读取、重裁剪、移除、作用域／只读／来源／归档／并发保护、图片解码和方向纠正，并仅清理该测试创建的资源。还覆盖 1410×600 输出、旧比例写入拒绝、旧图字节／元数据读取不变及选区适配。组件检查在 `npm run test:admin-ui`，覆盖贴边图片列、编辑页无渐隐和 2.35:1 网格。

`npm run test:server-motto:browser` 对已启动预览使用 Playwright（配置与 Scalar 相同，`SMOKE_ORIGIN` 默认 localhost:3001）。真实登录后仅在浏览器拦截只读图片及状态请求，使用测试图片，不写业务服务器资料或图片；检查单元格零内边距及图片四边对齐、黑白主题末端像素、完整编辑预览、旧图选区适配、键盘移动、鼠标拖动及重置。截图存放在忽略目录 `.local/motto-*.png`。该测试已加入 CI，远端执行仍须推送后触发；触摸设备实测未覆盖。
