# 界面语言与黑白主题

登录页右上方和管理界面顶部提供语言／主题按钮，所有账号均可使用，不需要 MUA 超管权限。支持简体中文（`zh-CN`）和英文（`en-US`）；默认简体中文、白色主题。主题按钮在白色／黑色之间切换，不强制跟随操作系统。

语言 Cookie `mua-locale` 保存一年（Path=/、SameSite=Lax，HTTPS 时 Secure），服务器在登录／后台认证通过之后读取并传给客户端 Context，保留原登录重定向状态。localStorage 同名键用于同源标签页同步。主题由已有 next-themes 保存至 localStorage `mua-theme`，通过 `html.dark` 驱动完整 CSS 变量。首屏脚本在绘制前恢复已保存主题与 `html.lang`，避免先显示错误主题；状态来自枚举白名单，不将 Cookie 内容直接插入脚本。

切换立即更新组件文案，保留正在填写的表单与既有 `/admin` 路由。业务名称、组织别名、用户填写的简介／Markdown、服务器地址、版本号、文件名及接口权限标识不翻译或改写。词典和模板仅用于界面文案、已知校验／探测提示；无法识别的底层诊断保留原信息，避免隐藏错误。

`src/lib/i18n.ts` 提供类型化 locale、`translate`／`translator`、占位符插值和上海时区的本地化日期；词典在 `src/lib/locales/en.json` 与 `extra-en.json`。UI 使用 `useI18n`，共享表单显示翻译后的标签和校验提示，静态列定义在渲染时使用当前词典。未来新增语言需扩展 Locale、语言按钮及完整词典。仅在明确的界面文案边界调用翻译，不遍历 DOM 或批量替换用户内容。

黑色主题覆盖页面、侧栏、弹窗、卡片、表格、输入框和 Toast；探测灯保留原颜色。服务器箴言图片继续按既有要求向白色淡出，空图文字在白色图片区域保持可读，不改变图片对象或签名。

验证包括词典插值完整性、中／英文登录／Settings／表格、业务内容保留、探测提示／日期、既有 RBAC 和发布格式回归，以及实际带 Cookie 的中英文页面和未登录重定向。生产构建检查 Cache Components 的请求边界。浏览器自动化桥不可用时，需明确区分这些检查与实际鼠标／截图验收。
